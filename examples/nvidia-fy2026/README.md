# NVIDIA FY2026 owner-letter example

This is an independent example of the owner-letter skills applied to a real public company. It is not a NVIDIA communication and is not affiliated with or endorsed by NVIDIA. It makes no investment recommendation.

The letter uses NVIDIA's FY2026 Form 10-K and full-year results release. [`02-source-notes.md`](02-source-notes.md) identifies the sources, calculations, distinctions, and interpretation boundary behind the draft.

Build the PDF from the repository root:

```sh
python3 scripts/build-book.py examples/nvidia-fy2026 \
  --output output/pdf/nvidia-fy2026-letter.pdf
```
